Proyek ini menggunakan Variabel Global dan Lokal, String dan Integer, Implementasi GUI Component (JList, JTextArea, JTextField), JButton.
Variabel Lokal : menu, jumlah, harga
Variabel Global : keranjangPesanan, totalHarga

Tampilan Aplikasi 
1. No. Meja untuk mengisi nomor tempat duduk
2. Pemesan untuk mengisi nama pelanggan
3. Kategori untuk memilih jenis menu
4. Menu berisi menampilkan daftar pilihan makanan
5. Jumlah Pesanan menampilkan jumlah menu yang akan dipesan
6. Harga untuk menampilkan harga setiap menu
7. Tombol Total untuk menampilkan total seluruh pesanan
9. Detail Pesanan menampilkan apa saja yang dipesan
10. Tombol Pesan untuk membuat pesanan
11. Tombol Reset untuk menghapus data 
    
Cara Menjalankan Aplikasinya =
1. Buka project di NetBeans
2. Jalankan file utamanya
3. Isi data : no. meja, nama, pilih kategori menu (Makanan, Minuman, Snacks), pilih menu, jumlah pesanan, harga akan otomatis muncul saat memilih menunya, dan pencet total.
4. Setelah total sudah muncul didetail pesanan, pencet tombol pesan, dan hasil akan muncul.
5. tombol reset jika ingin mengulangi pesanan atau menghapus pesanan
